# Decision Log

A running record of key decisions made throughout the project.  
Each entry includes the decision, the context, and the rationale.

---

## Decision 001 — PM-First Approach Until AI-900 Is Complete
**Date:** 2026-05-09  
**Context:** Limited daily time; AI-900 is the priority.  
**Decision:** Focus on PM artifacts, repo structure, and planning before coding.  
**Rationale:** Keeps momentum without opening technical loops; aligns with exam prep.

---

## Decision 002 — 30-Minute Daily Cadence
**Date:** 2026-05-09  
**Context:** Solo project with real-life constraints.  
**Decision:** Work in small, consistent, presence-friendly blocks.  
**Rationale:** Sustainable pace; avoids burnout; fits parenting and work rhythms.

---

## Decision 003 — Azure Vision as Baseline Model
**Date:** 2026-05-09  
**Context:** Need a fast, low-friction starting point.  
**Decision:** Use Azure Vision for the MVP before exploring custom training.  
**Rationale:** Reduces setup complexity; accelerates end-to-end demo.

## Decision 004 — MVP Limited to Enduro Bike Classification
**Date:** 2026-05-09  
**Context:** Temptation to expand categories early.  
**Decision:** Keep MVP focused on enduro bikes only.  
**Rationale:** Prevents scope creep; ensures a clean, demonstrable outcome.
